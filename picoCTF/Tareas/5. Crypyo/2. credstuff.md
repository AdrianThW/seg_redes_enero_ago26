#### Description

We found a leak of a blackmarket website's login credentials. Can you find the password of the user `cultiris` and successfully decrypt it? Download the leak [here](https://artifacts.picoctf.net/c/151/leak.tar). The first user in `usernames.txt` corresponds to the first password in `passwords.txt`. The second user corresponds to the second password, and so on.

```
adrian@ThW:~/Documents/adicional_seg/crpyto$ tar -xvf leak.tar || ls 
leak/
leak/passwords.txt
leak/usernames.txt
adrian@ThW:~/Documents/adicional_seg/crpyto$ cd leak/
adrian@ThW:~/Documents/adicional_seg/crpyto/leak$ cat usernames.txt | grep 
passwords.txt  usernames.txt  
adrian@ThW:~/Documents/adicional_seg/crpyto/leak$ cat usernames.txt | grep cultiris
cultiris
adrian@ThW:~/Documents/adicional_seg/crpyto/leak$ cat passwords.txt 
CMPTmLrgfYCexGzJu6TbdGwZa
GK73YKE2XD2TEnvJeHRBdfpt2
UukmEk5NCPGUSfs5tGWPK26gG
kaL36YJtvZMdbTdLuQRx84t85
```

La flag encriptada esta en la misma linea que se encuentra el user.
