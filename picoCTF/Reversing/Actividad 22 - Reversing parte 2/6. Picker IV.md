`objdump` es una ==herramienta de línea de comandos en sistemas tipo Unix (GNU Binutils) utilizada para visualizar información detallada de archivos objeto y binarios ejecutables==. Sirve principalmente para desensamblar código (convertir binario a ensamblador), inspeccionar encabezados ELF, analizar secciones de memoria y realizar ingeniería inversa o depuración. 

**Usos principales de `objdump`:**

- **Desensamblado (`-d`):** Convierte el código de máquina binario en lenguaje ensamblador legible, fundamental para entender cómo funciona un programa. 
With Python, there are no binaries. With compiled languages like C, there is source code, and there are binaries. Binaries are created from source code, they are a conversion from the human-readable source code, to the highly efficient machine language, in this case: x86_64.
